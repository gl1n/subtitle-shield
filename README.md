# 字幕遮挡器

一个基于 Manifest V3 的 Chromium 浏览器扩展，用可调整的毛玻璃区域遮住视频字幕。适合观看字幕无法关闭、位置固定，或希望临时隐藏字幕的视频。

## 功能

- 在视频画面或播放器区域拖动选择遮挡范围
- 拖动遮挡区域，或使用四角手柄调整大小
- 支持自动水平居中
- 支持显示/隐藏遮挡层、关闭当前遮挡和清除当前网站配置
- 配置按网站来源保存，刷新页面后仍可使用
- 支持全屏视频，以及嵌入式播放器 iframe
- 支持键盘快捷键切换遮挡层和进入编辑模式
- 使用 `backdrop-filter` 提供毛玻璃效果

## 安装

项目当前没有构建步骤，可以直接作为未打包扩展加载到 Chrome、Microsoft Edge 或其他支持 Manifest V3 的 Chromium 浏览器中。

1. 下载或克隆本项目。
2. 打开浏览器的扩展管理页面：
   - Chrome：`chrome://extensions`
   - Edge：`edge://extensions`
3. 打开右上角的“开发者模式”。
4. 点击“加载已解压的扩展”，选择本项目根目录。
5. 将“字幕遮挡器”固定到工具栏，方便打开控制面板。

修改源文件后，在扩展管理页面点击扩展卡片上的刷新按钮即可加载最新内容。

## 使用

1. 打开包含视频的网页。
2. 点击工具栏中的“字幕遮挡器”图标。
3. 点击“选择遮挡区域”，在视频画面上拖出需要遮挡的区域。
4. 通过拖动区域或四角手柄微调位置和尺寸。
5. 点击“完成”保存。

弹窗中的选项：

- “遮挡层”：显示或隐藏已经保存的遮挡区域。
- “自动居中”：编辑或调整后，将遮挡区域自动移动到视频水平方向的中央。
- “清除当前网站配置”：删除当前网站保存的遮挡区域及相关开关状态。

遮挡层显示时，也可以点击遮挡区域右上角的 `×` 临时关闭它；这不会删除已保存的区域。

### 快捷键

| 操作 | Windows / Linux | macOS |
| --- | --- | --- |
| 显示或隐藏遮挡层 | `Ctrl + Shift + Y` | `⌘ + Shift + Y` |
| 调整遮挡区域 | `Ctrl + Shift + U` | `⌘ + Shift + U` |
| 取消编辑 | `Esc` | `Esc` |

如果快捷键与其他扩展或浏览器功能冲突，可以在扩展管理页面的“键盘快捷键”中修改。

## 本地测试页

项目包含一个不依赖外部资源的测试页：[`demo/index.html`](demo/index.html)。推荐通过本地静态服务器访问，以便浏览器正常注入扩展内容：

```bash
python3 -m http.server 8080 --directory demo
```

然后打开 <http://localhost:8080>。如果直接打开 `file://` 页面没有出现遮挡器，请在扩展管理页面为该扩展开启“允许访问文件网址”，或改用上面的本地服务器方式。

## 开发

运行单元测试：

```bash
npm test
```

项目不需要安装 npm 依赖。测试使用 Node.js 内置的 `node:test` 运行，主要覆盖：

- 遮挡区域的坐标归一化、边界限制和自动居中
- `object-fit: contain` 视频的实际画面区域计算
- iframe 场景下的编辑入口选择
- 多 frame 状态选择
- 默认状态和清除配置行为

## 权限与隐私

扩展使用以下浏览器能力：

- `storage`：在本地保存每个网站的遮挡区域和开关状态
- `activeTab`、`scripting`：在当前标签页及必要的 frame 中初始化或恢复遮挡层
- `webNavigation`：获取当前标签页的 frame 列表，以支持嵌入式播放器
- `commands`：注册上面的键盘快捷键

扩展没有联网、埋点或远程数据上传逻辑。配置保存在浏览器的本地扩展存储中。

## 已知限制

- 浏览器通常禁止扩展访问 `chrome://`、扩展管理页、Chrome Web Store 等受保护页面。
- 页面必须存在可识别的视频，或存在尺寸足够大的播放器 iframe，才能进入编辑模式。
- 同一网站的配置按来源保存；不同子域名可能分别拥有独立配置。
- 毛玻璃效果依赖浏览器的 `backdrop-filter` 支持。
