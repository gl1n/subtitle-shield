# 字幕遮挡器

一个 Manifest V3 浏览器扩展，用可调整的毛玻璃区域遮住视频字幕，适合观看没有字幕开关或字幕位置固定的视频。

## 功能

- 在当前网页的视频或播放器区域选择遮挡范围
- 拖动遮挡区域，或通过四角手柄调整尺寸
- 支持自动水平居中、关闭遮挡和清除当前网站配置
- 配置按网站来源保存
- 支持快捷键切换遮挡层和进入编辑模式

## 安装

项目没有构建步骤，可直接作为未打包扩展加载：

1. 打开 Chromium 系浏览器的扩展管理页面，并开启“开发者模式”。
2. 选择“加载已解压的扩展”，选中本项目根目录。
3. 打开包含视频的网页，点击工具栏中的“字幕遮挡器”图标。

## 使用

点击“选择遮挡区域”，在视频画面上拖动出需要遮挡的区域，然后点击“完成”。之后可以通过弹窗开关控制显示状态。

- `Ctrl/Cmd + Shift + Y`：显示或隐藏遮挡层
- `Ctrl/Cmd + Shift + U`：调整遮挡区域
- 编辑时按 `Esc`：取消本次编辑

## 开发

运行单元测试：

```bash
npm test
```

本地测试页位于 [`demo/index.html`](demo/index.html)，可通过浏览器直接打开，或由本地静态服务器提供访问。

## 目录结构

```text
├── manifest.json              # 扩展入口和权限配置
├── src/
│   ├── background/            # Service Worker
│   ├── content/               # 页面遮挡层及样式
│   ├── popup/                 # 扩展弹窗
│   └── shared/                # 页面和测试共用的几何工具
├── demo/                      # 本地测试页面
└── test/                      # 单元测试
```
